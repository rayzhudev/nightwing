No Swift Package Manager, CocoaPods or Carthage dependencies are configured. Apple's system frameworks are not copied into the app as third-party libraries. This inventory does not assert independent provenance or a licence grant for the app's icon artwork; the app owner must retain the rights to its own project assets.

### Bundled online media tools — 0.3.1 (4)

All executables and CPython native modules are universal arm64/x86_64 and signed with Nightwing's Developer ID. The app invokes the downloader and FFmpeg as **separate processes**, not linked proprietary modules. `Contents/Resources/MediaTools/INPUTS.json` pins input URLs/SHA-256; `INVENTORY.json` records every staged file/hash. Complete notices are in `Notices/`; exact FFmpeg source and build recipe ship in `CorrespondingSource/`. These files are also available in the [public build recipe and lockfile](https://github.com/rayzhudev/nightwing/tree/main/scripts).

- **yt-dlp 2026.10.26**: Unlicense core source from the pure-Python PyPI wheel. This is **not** upstream's GPLv3+ PyInstaller combined executable. Nightwing uses its own small CPython launcher and includes no PyInstaller, mutagen, pycryptodomex, curl_cffi, requests or websockets distribution. Do not apply this licence conclusion to arbitrary upstream binaries.
- **yt-dlp-ejs 0.8.0**: Unlicense; included solver JavaScript also contains **Meriyah 6.1.4 (ISC)** and **Astring 1.9.0 (MIT)**. Their complete notices remain at the head of `site-packages/yt_dlp_ejs/yt/solver/lib.min.js`.
- **CPython 3.14.10**: extracted from the official PSF-signed universal installer (not installed system-wide), relocated and pruned. PSF/Python licence stack is preserved in `Notices/CPython-LICENSE.txt`. Included Python native code also contains **OpenSSL 3.5.9 (Apache-2.0)**, **liblzma from XZ 5.2.3 (public-domain library)**, **Expat 2.9.0 (MIT; exact vendored source revision in CPython source)** and **HACL* (MIT; exact vendored source and notices included)**. Tcl/Tk, ncurses, SQLite, Berkeley DB, zstd, libmpdecimal and their Python extension modules are omitted. Apple-provided system libraries (including libffi, bzip2 and zlib) are linked but not redistributed. PSF installer build recipes identify the exact static dependency inputs; see [provenance](https://github.com/rayzhudev/nightwing/blob/main/docs/DEPENDENCY_PROVENANCE.md).
- **certifi 2026.10.23**, Mozilla CA bundle and Python code: **MPL-2.0**. The unmodified wheel in `CorrespondingSource/` contains the exact redistributed source form, including `cacert.pem`; its licence is preserved in `Notices/PythonPackages`. Source is supplied with the app rather than promised for later.
- **FFmpeg and ffprobe 8.1.3**: unmodified upstream source, compiled **LGPL-2.1-or-later**, without GPL/nonfree/version3 code or third-party non-system libraries. No external codecs are auto-detected. The tools are statically linked from that source, not linked to Nightwing; complete matching source, build instructions and LGPL texts accompany **every app**. Recipients may modify/rebuild these tools under their licences; this does not grant rights to Nightwing itself. Network protocols are disabled in FFmpeg; the downloader supplies local media files.

The LGPL/MPL source requirement is met by accompanying exact source; **no unsubstantiated written source offer is used**. The historical GPLv3+ downloader remains excluded. App licensing does not limit recipients' rights in these third-party materials. Codec patents and rights to media are separate from software copyright licences.
