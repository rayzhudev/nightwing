## 0.3.1 bundled-media packaging boundary

The new candidate is local only, not notarized or published. It adds a sealed universal media payload to the universal Swift app. The existing 0.3.0 public release is unchanged. All downloaded inputs are pinned by URL and SHA-256 in `scripts/media-tools.lock.json`; the staged signed-file inventory is `Nightwing.app/Contents/Resources/MediaTools/INVENTORY.json`. All distribution paths call `scripts/build-media-tools.py` before the outer app signature. Native helpers live under Contents/MacOS/MediaTools; CPython/native extensions under Contents/Frameworks, pure Python stdlib under Resources/MediaTools/python. No user installation or mutable helper cache is executed.

### Why the historical GPL downloader is not restored

The old upstream `yt-dlp_macos` 2026.08.19 (SHA-256 `0f192b7ec147ab6288885d6351d9ab67367640029b4377576ef46dd79cf7b202`) was an upstream-declared GPLv3+ PyInstaller combined work. Its full exact corresponding source/source offer was not substantiated and it remains excluded. The replacement is **not that binary**: a small repository-owned C launcher embeds the PSF-licensed CPython framework and runs the unmodified pure-Python yt-dlp wheel in isolated mode. No PyInstaller or GPL optional downloader libraries are present. No GPL exception or blanket core-only claim is applied to an upstream combined executable.

### Exact payload and licensing evidence

See `docs/Public/THIRD_PARTY_NOTICES.md` for component versions/licences. The hash lock records original release archives, pure-source wheels and notice archives. Node archives are compared with upstream SHASUMS256; Python's official installer is verified by pkgutil (PSF Developer ID Installer BMM5U3QVKW), extracted without installing, and used as the versioned universal payload. Its original notarization **does not notarize Nightwing**. Python's source archive supplies its full licence stack, Expat notice and HACL vendored sources. `Mac/BuildScript/build-installer.py` in that exact CPython archive pins OpenSSL 3.5.9 and XZ 5.2.3; their exact archives/notices are hash-locked too. The runtime is pruned of Tcl/Tk, SQLite, Berkeley DB, ncurses, zstd and mpdecimal extensions; it retains only libpython, libssl, libcrypto and stdlib native modules with system-only or relocated bundled dependencies. It is no longer a complete general-purpose Python installation.

FFmpeg 8.1.3 is built from its exact source twice using Apple's clang/Xcode SDK and merged with lipo. Configure explicitly disables GPL, nonfree, shared libraries, autodetected external libraries and networking, with no version3 option. FFmpeg's own -version/-buildconf output is acceptance evidence. The complete unmodified source tar, exact standalone rebuild-ffmpeg.sh and configure/make recipe and all LGPL notices accompany each app under CorrespondingSource. No proprietary object is linked into these executables. This supplies actual matching source, not a future written offer. Certifi's MPL source is the exact accompanying unmodified pure-source wheel. yt-dlp/EJS source wheels also accompany the app. Node's complete upstream LICENSE (including all bundled notices) is preserved, not replaced with only its top-level MIT text.

### Build and verification

`python3 scripts/build-media-tools.py` fetches only pinned inputs, prepares the payload and builds FFmpeg. Requires Xcode command line tools and Python 3; **no Homebrew dependency**. `--stage APP` copies payloads, signs every native object with Developer ID/hardened runtime and grants Node and the isolated CPython launcher allow-jit plus allow-unsigned-executable-memory for V8/system-libffi executable trampolines on Intel/Rosetta; no disable-library-validation entitlement is used. The outer app is signed last. `--verify APP` checks every inventory hash and runs all four tools natively and under Rosetta, including actual Node JavaScript evaluation. Cross-architecture FFmpeg is source-rebuildable; this is not a byte-reproducible/Xcode-independent build claim. A lock/recipe change invalidates the staged payload; FFmpeg build flags are compared with the cached configuration before reuse.

`python3 scripts/package-developer-preview.py` builds clean HEAD into a new 0.3.1 (4) signed local candidate, checks app/docs/source identity, validates the exact extracted ZIP and requires expected unnotarized Gatekeeper rejection/no stapled ticket. It never submits to Apple or uploads release assets. `scripts/verify-media-tools.py APP --evidence DIRECTORY` exercises actual sealed-tool discovery, forced WAV-to-AAC extraction, isolated cache/import/playback on arm64 and Rosetta using a disposable localhost fixture. Public provider probing is separately logged, not a guarantee of provider availability. `scripts/verify-candidate.sh` retains the offline/core acceptance flow.

User data, provider-terms, no-implicit-cookies and network disclosures remain in docs/Public/PRIVACY.md. Optional on-demand transcription is a separate dependency boundary; its uv-managed Python/model are not silently substituted for the bundled downloader runtime. No new artwork, Swift packages, Pods or Carthage modules were added. The owner has not granted a project-wide open-source licence; third-party licences and recipient rights remain unaffected.
